# Tellin 1.0.0

## 中文

- Tellin 的第 1 个公开发布版本，免费使用，源码不公开。
- 支持本地听写、说话整理、中文翻译成英文和记错词；整理与翻译可接入自己的模型服务。
- 安装包内置 Qwen3-ASR 0.6B，首次使用无需另行下载识别模型。
- 仅支持 Apple 芯片 Mac（M1 及以后），macOS 11 或更新。
- 尚未经过 Apple 公证，首次打开请按 README 在系统设置中点「仍要打开」。

## English

- Tellin's first public release. Free to use; source code is not public.
- Includes local dictation, speech cleanup, Chinese-to-English translation and word corrections; connect your own model service for cleanup and translation.
- Qwen3-ASR 0.6B is bundled, with no separate recognition-model download required on first use.
- Apple silicon Macs only (M1 or later), running macOS 11 or later.
- Not notarized by Apple. Follow the README and use Open Anyway in System Settings for the first launch.
