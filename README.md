# Tellin

**Tellin：Mac 上的语音输入。说完，整理好的文字直接落到光标处。**

[**下载 Tellin · Apple 芯片 Mac**](https://github.com/LK66LK/tellin/releases/latest)

免费使用。语音识别在本机完成；需要整理或翻译时，接入你自己的模型服务。

## 1. 能做什么

以下整理效果以接入整理模型为前提，例子用于说明，实际结果可能不同。

- **说话**：去掉口头禅、保留改口后的最终说法，不同事情分成「1. 2. 3.」小节，日期、时间和编号使用阿拉伯数字；例如「嗯，周二开会，不对，周三，编号二六幺零二零」可整理为「周三开会，编号 261020」。
- **本地听写**：只识别、不调用整理模型，离线可用；例如把「明天下午三点开会，记得带合同」写进备忘录。
- **翻译成英文**：说中文，直接写出英文，可选「口语」或「正式」；例如「明天下午三点开会」可写成「The meeting is at 3 PM tomorrow.」。
- **记错词**：选中听错的词，按快捷键填写正确写法，加入词典供以后纠正；例如把「海兰项目」记为「海岚项目」，仍建议检查重要人名和数字。

## 2. 系统要求

- Apple 芯片的 Mac：M1 及之后。Intel 芯片的 Mac 不支持。
- macOS 11 或更新。作者测试使用 macOS Tahoe 26.6.2 和 macOS Tahoe 26.3.1(a)；其他版本未逐一实测。
- 安装包和模型约需 2 GB 空间。安装时还要解压和复制模型，建议预留更多空间；历史录音会另占空间。

## 3. 下载和安装

### 3.1 下载

1. 打开上方的下载链接。
2. 在版本页面找到 **Assets**（下载文件），点 `Tellin_1.0.0_aarch64.dmg`。不要下载 `Source code`，那不是安装包。
3. 安装包实测为 **824,357,057 字节，约 824 MB（786 MiB）**。下载耗时尚未实测，取决于网络和 GitHub 连接速度。

### 3.2 打开 DMG

1. 双击下载的 DMG。系统可能先显示「正在验证」。请预留大约 1 分钟，不要看到进度条就取消；这是等待参考，并非实测耗时，具体以电脑为准。
2. 安装窗口左边是 Tellin 图标，中间是蓝色箭头，右边是「应用程序」。把 **Tellin 拖到「应用程序」**，等复制结束。
3. 底部浅绿提示条介绍首次打开的方法。安装完成后，可推出 Tellin 磁盘。

下载文件可能显示系统默认的白色图标，不影响安装；打开后才会看到 Tellin 的磁盘和安装窗口。

### 3.3 第一次打开会被系统拦下

Tellin 1.0.0 尚未经过 Apple 公证，作者没有加入付费 Apple Developer Program（标准年费为 99 美元）。因此 macOS 无法验证开发者。这个提示本身不等于发现恶意软件，也不等于安全认证；请只从本仓库下载。参见 [Apple 的打开应用说明](https://support.apple.com/en-us/102445)和[开发者计划说明](https://developer.apple.com/programs/)。

macOS 15 及以后：

1. 从「应用程序」双击 Tellin，出现拦截提示后点「完成」。

![首次打开 Tellin 的系统提示](images/01-first-open-blocked.png)

2. 打开 **系统设置 → 隐私与安全性**，向下找到关于 Tellin 的提示，点「仍要打开」。按系统要求输入开机密码，再确认打开。

![在隐私与安全性中允许打开 Tellin](images/02-open-anyway.png)

旧版 macOS 可以尝试右键点 Tellin →「打开」；没有此选项时，使用系统安全性设置中的「仍要打开」。同一版本通常只需处理一次。

看到「已损坏，无法打开」时，按第 9 节第 1 条排查。

### 3.4 第一次启动

1. 「需要权限」页有「麦克风访问」和「辅助功能访问」。分别点「授予权限」，按第 4 节完成授权。成功后显示「全部完成！」。
2. App 已内置 Qwen3-ASR 0.6B 识别模型，首次启动会复制并选中，不用另行下载。通常会直接进入首页。可先等待大约几秒；这是参考时间，首次启动耗时尚未实测。
3. 首页会出现「还差一步：接上整理模型」，默认选择「DeepSeek · 推荐」。你可以按第 6 节接入，也可以先用本地听写。

## 4. 授权

### 麦克风

用来听你说话。在「需要权限 → 麦克风访问」点「授予权限」，系统询问时点「允许」。如果以前拒绝过，到 **系统设置 → 隐私与安全性 → 麦克风 → Tellin** 打开开关。

![允许 Tellin 使用麦克风](images/03-microphone.png)

### 辅助功能

用来响应全局快捷键、把文字写进当前软件，并支持你主动启用的纠词操作。点「需要权限 → 辅助功能访问 → 授予权限」，再点系统弹窗里的「打开系统设置」。

![打开辅助功能设置](images/04-accessibility.png)

进入 **系统设置 → 隐私与安全性 → 辅助功能**，打开 Tellin 的开关，然后回到 Tellin。没有开启时，快捷键可能没反应，或文字无法落下。旧版 macOS 的对应入口可能叫「系统偏好设置 → 安全性与隐私 → 隐私」。

录音在本机识别。辅助功能权限还用于你选择的文字纠错；不是上传录音的授权。

## 5. 开始用

这是完成设置后的首页。图中的数字和快捷键只是这台测试机的状态。

![Tellin 首页与快捷键位置](images/05-home.png)

快捷键可以在首页右边改，以你 App 里显示的为准。

| 功能 | 默认快捷键 | 做什么 |
|---|---|---|
| 说话 | ⌥ ⇧ 空格 | 轻按开始，再轻按结束，整理后写到光标处 |
| 本地听写 | ⌥ 空格 | 只识别，不调用整理模型，离线可用 |
| 翻译成英文 | 左 ⌃ + 左 ⌥ + T | 说中文，结束后写出英文 |
| 记错词 | ⌃ ⌥ D | 先选中听错的词，再按快捷键填写正确写法 |
| 取消录音 | Esc | 取消，不写入文字 |

⌥ 是 Option，⇧ 是 Shift，⌃ 是 Control。首页列出「说话」「记错词」「翻译成英文」「取消录音」；「本地听写」在 **设置 → 通用 → 转录快捷键** 修改。

试一次：

1. 打开微信或备忘录，把光标放进可输入文字的位置。
2. 轻按 **⌥ ⇧ 空格**。
3. 说「明天下午三点开会，记得带合同」。
4. 再轻按一次，等待文字落下；发送消息前检查内容。

**设置 → 通用 → 快捷键行为** 有 3 个选项：

| 选项 | 什么时候选 |
|---|---|
| 自动（默认） | 轻按可以开始／停止，也可以按住录音、松开结束；两种习惯都想保留时选它 |
| 按住 | 只想按住说话、松开结束时选它 |
| 切换 | 想腾出双手，按一下开始、再按一下结束时选它 |

如果想每次都能手动粘贴结果，在 **设置 → 高级 → 输出 → 剪贴板处理** 选「复制到剪贴板」；选「不修改剪贴板」则保留原剪贴板内容。

## 6. 接入 DeepSeek（可选）

不接整理模型也能用：「说话」仍可识别并做本地基础清理、套用词典；「本地听写」不受影响。「翻译成英文」需要可用的整理模型，没接好时会提示失败，并把中文放进剪贴板。

Tellin 推荐 DeepSeek。首页也提供「智谱 · 免费」试用入口；App 对这一路径的提示是分段和改错效果不如 DeepSeek，适合先试用。实际效果、可用性和服务商价格可能变化。

1. 在首页「还差一步：接上整理模型」选择「DeepSeek · 推荐」，点「注册 / 登录」，打开 [DeepSeek 开放平台](https://platform.deepseek.com/)。
2. 按平台提示注册。打开「充值」，可先充 ¥10；这笔钱直接付给 DeepSeek，Tellin 不收费。
3. 打开平台的「API keys → 创建 API key」，复制生成的 Key（通常只完整显示一次），不要发给别人。
4. 回到 Tellin 首页，粘贴 Key，点「保存并测试」。看到浅绿的「✓ DeepSeek 已接好」即表示测试成功。
5. 以后检查连接：**设置 → 整理模型 → 测试连接**。更换 Key：**设置 → 整理模型 → API Key → DeepSeek API Key**。

费用按服务商用量计费。作者给出的日常使用参考估算约 **¥1.25／月**，不是固定月费或实测保证；实际随模型、字数和调用次数变化，以 DeepSeek 账单为准。

**备用模型**在 **设置 → 整理模型 → 备用模型**。可以选其他提供商并配置，也可以选「不用备用」。App 的说明是：

> 可不填。主力 1.5 秒（长段落按字数顺延）没回或出错时，会把同一段话也发给备用模型，两边都可能计费。只想用主力就选「不用备用」。

Key 默认通过 Mac 钥匙串保存，设置页只显示末尾 4 位，点「移除」可移除已保存的 Key。当前版本在钥匙串写入失败时存在本地设置文件回退，因此不要分享自己的应用数据文件夹。

## 7. 常用设置

### 7.1 改快捷键

- **位置**：首页 → 快捷键 → 对应功能 →「改」。点后按下新组合。本地听写在 **设置 → 通用 → 转录快捷键**，取消键在同页「取消快捷键」。
- **可选**：自定义组合键。避免 ⌘N、⌘C、⌘V 等常用组合，也不要重复占用另一项功能的快捷键；设置冲突时换一个组合。
- **快捷键方式**：在 **设置 → 通用 → 快捷键方式**。默认「Tellin 键盘（推荐）」支持只按修饰键，按住说话更稳；只有它不灵时，再试「系统快捷键」。

### 7.2 麦克风

- **位置**：设置 → 通用 → 声音 → 麦克风。
- **可选**：系统默认或当前连接的输入设备。
- **建议**：先用 Mac 自带麦克风。蓝牙耳机麦克风可能降低录音质量，影响识别。自动选择会避开已识别的远程控制虚拟麦克风；仍选错时手动指定设备。

### 7.3 整理风格

- **位置**：风格 → 我的规则。
- **结尾自动加**：填写固定尾缀，例如 `//`；可以勾选「只在 AI 与编程 App 里加（Claude、ChatGPT、Codex、Cursor 等）」。需要分隔连续输入时使用，不需要就留空。
- **补充给整理模型的要求**：输入最多 500 字，例如「不要用感叹号」，点「保存」。填写后短句也会交给模型，可能增加耗时和费用；不需要额外要求就留空。
- **按 App 调整口吻**：风格 → 按 App 调整口吻，或设置 → 高级 → 转录 → 按应用调整口吻。打开后聊天保留口语，给 AI 的不同要求分条；希望所有软件使用同一规则就关闭。

### 7.4 翻译风格

- **位置**：首页 → 快捷键 → 翻译成英文。
- **可选**：「口语」适合聊天；「正式」适合邮件和工作文字，默认是「正式」。
- 需要接入整理模型，修改风格不会替你发送文字。

### 7.5 词典

1. 打开 **词典 → + 新词**。
2. 在「正写」填正确写法，在「常被听成」填误听写法，多个写法用逗号分隔；「备注（可不填）」用于帮助自己辨认。
3. 点「保存」。已有词条可以点「改」修改或删除。

新装词典是空的，只列出你自己添加或确认的词，这是正常的。

| 选项与位置 | 怎么选 |
|---|---|
| 词典 → 识别常见 AI 名词 | 默认开启，约 30 个常用工具名会供整理模型按上下文参考，例如「克劳德」→ Claude；不占词典列表，需要整理模型，本地听写不使用这组云端纠错提示。不常说工具名或发现误改时关闭 |
| 词典 → 识别时就参考词典（实验） | 默认关闭；常说词典里的人名、术语时可试开，发现无关词被带偏时关闭 |
| 设置 → 高级 → 转录 → 自动学习改过的词 | 开启后，在支持读取的输入框里修改刚落下的短词，Tellin 会询问是否记住；只有确认才入词典。不希望出现询问就关闭；并非所有编辑器都支持，密码框不读取 |

### 7.6 历史记录与录音

- **查看与搜索**：左侧「历史记录」，搜索框可查原话或整理后的文字；可筛选记录。点「用原话」复制识别原文，或复制整理结果。
- **条数**：设置 → 高级 → 历史 → 历史记录上限，默认 500 条，可输入条数。需要回查时保留较多，不需要长期保存时减少。
- **音频**：设置 → 高级 → 历史 → 自动删除录音，可选「从不」「保留最新 N 条」「3 天后」「2 周后」「3 个月后」。默认按最新条数保留；想省空间可选短期限，需留存音频再选「从不」。删除音频后不能再播放该段录音。

### 7.7 悬浮窗和启动

| 位置 | 选项与建议 |
|---|---|
| 设置 → 高级 → 应用 → 悬浮窗 | 「精简」只显示录音状态；「实时」边说边显示文字，需要支持流式的模型；「无」隐藏悬浮窗 |
| 设置 → 高级 → 应用 → 开机启动 | 开启后登录 Mac 自动启动 Tellin；只偶尔用就关闭 |
| 设置 → 高级 → 应用 → 隐藏启动 | 开启后启动时不弹主窗口，从菜单栏打开；希望先看到首页就关闭 |

### 7.8 识别模型空闲释放

**位置**：设置 → 高级 → 转录 → 识别模型空闲释放。

可选「从不」「立即」「2 分钟后」「5 分钟后」「10 分钟后」「15 分钟后」「1 小时后」「15 秒后（调试）」。经常说话选「从不」或「1 小时后」，减少重复加载；想省内存选较短时间。释放后下一次录音会重新加载，可能多等几秒；普通使用不必选调试项。

## 8. 隐私

- 录音在本机识别，不上传录音。
- 使用云端整理或翻译时，识别文字、整理规则和用于纠错的词典参考会发给你选择的服务商；启用备用模型时也可能发给备用服务商。
- 未接入云端模型时，本地听写不需要网络。安装包已含识别模型；另下载模型或打开平台链接需要网络。
- Key 默认保存在钥匙串；钥匙串写入失败时可能回退到本地设置文件。不要分享应用数据目录。
- 历史记录和录音保存在本机，可管理保留条数、设置自动删除录音。
- Tellin 没有使用统计上报、没有广告，也不会自动检查更新。首页使用统计在本机计算。

## 9. 常见问题

### 9.1 打不开、提示「已损坏」或无法验证开发者

**无法验证开发者**：通常与未公证有关，按第 3.3 节操作。

**已损坏**：可能是下载不完整、文件被改动或系统隔离限制，不能只凭这句话确定原因。先从本仓库重新下载，确认文件来源及 Release 附带的 SHA-256 校验值。确认文件完整且可信后，仍因隔离限制无法打开时，可在「终端」执行：

```bash
xattr -dr com.apple.quarantine /Applications/Tellin.app
```

这行命令只移除已安装 Tellin 的互联网下载隔离标记，会取消该标记触发的首次打开检查；不会修复损坏文件，也不是安全检测。不要用于来源不明的应用。执行后再打开 Tellin。

### 9.2 按快捷键没反应，或文字没落下

按顺序检查：

1. **权限没开**：系统设置 → 隐私与安全性 → 辅助功能，打开 Tellin。
2. **更新后失灵**：在该列表选中 Tellin，点「−」移除旧条目，再点「+」重新添加「应用程序」中的 Tellin，并打开开关。
3. **快捷键冲突**：在首页「快捷键」改成其他组合；本地听写在设置 → 通用 → 转录快捷键修改。
4. **光标在密码框或安全输入开启**：系统可能屏蔽快捷键，Tellin 会显示警告。退出密码输入，换到普通输入框再试。
5. **历史里有文字但没落字**：可能是输入框没获得焦点，或目标软件不接受自动粘贴。先点输入框；如果剪贴板有结果，按 ⌘V，否则在「历史记录」复制结果后粘贴。也检查设置 → 高级 → 输出 → 粘贴方式，不要选「无」。

### 9.3 识别不准

**现象**：漏字、错词。**可能原因**：麦克风、环境噪声或专有名词。**怎么做**：在设置 → 通用 → 声音 → 麦克风选择 Mac 自带麦克风，靠近一点说话；人名和术语加进「词典」，或选中误听文字用「记错词」。

### 9.4 整理没生效，或翻译没出英文

可能是 Key 无效、额度不足或服务暂时不可用。到 **设置 → 整理模型 → 测试连接** 检查，并在服务商平台确认余额；不要把 Key 发给他人排查。

### 9.5 有时候慢

久未使用后可能需要重新加载模型；云端请求也受网络影响。到 **设置 → 高级 → 转录 → 识别模型空闲释放** 选「从不」或「1 小时后」。若只想马上记下原话，可用本地听写。

### 9.6 怎么卸载

1. 先从菜单栏退出 Tellin，再把「应用程序」里的 Tellin 拖进废纸篓。
2. 若还要删除本地设置、模型和历史，在访达按 ⇧⌘G，进入 `~/Library/Application Support/com.sera.tellin`，确认不再需要里面的数据后删除该文件夹。
3. 在「钥匙串访问」搜索 `com.sera.tellin`，删除属于 Tellin 的 Key 条目。

### 9.7 已知问题

- 蓝牙耳机麦克风可能降低音质，建议使用 Mac 自带麦克风。
- 尚未经过 Apple 公证，首次打开需手动允许。
- 仅支持 Apple 芯片 Mac。

## 10. 怎么更新

Tellin 不会自动更新，也不会联网检查更新。新版发布在 [Releases](https://github.com/LK66LK/tellin/releases/latest)，同时由小红书 @Sera 通知。

1. 从 Releases 下载新版 DMG。
2. 退出 Tellin，把新版拖进「应用程序」，选择替换旧版。
3. 正常覆盖安装会保留设置、词典、历史记录和 Key；不要删除应用数据目录。更新后快捷键失灵时按第 9.2 节重新授权。
